Smoke Studies

Hand-drawn style smoke you can paint with, in the spirit of the 2D effects in Arcane. The same simulation rules and the same Style JSON drive three studies; only the number of dimensions changes, and with it the material the smoke seems to be made of.

  • 01 · 2D

    Brush

    One stable-fluids grid, toon shaded on the CPU: flat bands, hue-shifted shadows, age tint, mottle and drifting embers. Reads as smoke.
  • 02 · 2.5D

    Cards

    Every stroke is its own 2D fluid card placed in 3D space. Rotate the world and draw again to add depth, the way Arcane composites flat FX layers into a 3D shot. Still smoke, now with space.
  • 03 · 3D

    Volume

    Unbounded curl-noise particles you can orbit around, rendered either in screen space with the 2D rules or as a ray-marched voxel volume. Reads as liquid.
